# Sistema-de-turnos
Sistema de Gestión de Turnos - Página de Presentación

¡Bienvenido al proyecto! Esta es una página web básica estructurada para presentar una plataforma de gestión de turnos online. El proyecto está pensado como una práctica fundamental de maquetación utilizando HTML semántico puro, sin hojas de estilo (CSS) ni scripts (JavaScript).

📌 Descripción

El objetivo de esta página es brindar una introducción clara a un sistema de gestión de citas y turnos (denominado TurnoFácil). Explica de forma concisa qué es el producto, sus características principales y los pasos básicos para realizar una reserva.

🚀 Tecnologías Utilizadas

HTML5: Estructuración semántica del contenido.

🛠️ Estructura del Código

El documento sigue una estructura semántica limpia organizada con los siguientes elementos:

<!DOCTYPE html>: Declaración del tipo de documento HTML5.

<header>: Encabezado principal que contiene el nombre del proyecto (<h1>) y un subtítulo descriptivo (<p>).

<main>: Contenedor principal del contenido central.

<section>: Bloques lógicos para dividir el contenido en:

Presentación del sistema (<h2> y <p>).

Lista de características (<h2>, <ul> y <li>).

Explicación de cómo funciona (<h2>, <p>, <ul> y <li>).

<footer>: Pie de página con información de contacto y derechos de autor.

💻 Cómo Ejecutar el Proyecto

Clona o descarga este repositorio en tu computadora.

Navega hasta la carpeta del proyecto.

Abre el archivo index.html en tu navegador web de preferencia (Chrome, Firefox, Edge, Safari, etc.).
